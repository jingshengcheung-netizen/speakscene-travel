# 餐厅点餐 / Restaurant ordering

- **id:** `restaurant`
- **level:** A2-B1
- **goal:** Order food/drinks, ask about allergens, request the bill.

## Starter (coach opens)
> Hi, table for one? Here's the menu. Are you ready to order?

## Rubric focus
I'd like..., allergy, still/sparkling, check please.

## Session checklist
- [ ] Learner states need clearly
- [ ] Uses at least 3 scene-relevant phrases
- [ ] Can rewrite one awkward turn into natural English
- [ ] Ends with a polite closing line
